# 台中夜間機車兜風指南（TAICHUNG NIGHT RIDE）- 專案說明文件

## 一、網站主題與內容說明
本網站為主題資訊與在地探索網站，主題設定為**「台中夜間機車兜風路線指南」**。
內容鎖定台中地區適合夜晚騎行巡航的路線，依據夜景視野、彎道特性與海風直線進行分類整理，全站規劃四大具備明確功能的內容區塊：
1. **主視覺區（Hero Section）**：夜間騎行意象引導與快速導航入口。
2. **精選路線展示區（Route Section）**：望高寮、藍色公路、高美海風線、136 縣道赤崁頂四條路線卡片。
3. **路況指標區（Metrics Section）**：以數據化框呈現里程、騎乘時長、海拔與路面狀況。
4. **安全公約與頁尾（Safety & Footer）**：提醒保暖、大燈安全與低轉速防噪規範。

## 二、Layout 技術使用位置（對應 F04 & F05）
1. **Flexbox 使用位置**：
   - **導覽列（`.site-header`）**：使用 `display: flex; justify-content: space-between; align-items: center;`，讓 Logo 與導覽選單在桌面版橫向對齊兩端。
   - **Hero 內容區（`.hero-content` & `.hero-actions`）**：使用 `flex-direction: column` 與 `align-items: center` 控制標題、文字與按鈕的縱向彈性排列與間距。
   - **指標區（`.stats-flex-container`）**：使用 `display: flex; justify-content: space-between;`，搭配子項目的 `flex: 1` 讓 4 個數據卡片均勻平分橫向寬度。
2. **CSS Grid 使用位置**：
   - **路線展示區（`.route-grid`）**：使用 `display: grid; grid-template-columns: repeat(2, 1fr); gap: 24px;`，在桌面版建立對稱、整齊的 2 欄卡片系統，確保標題、標籤與說明文字具備齊整的垂直軸線。

## 三、RWD 設計差異與 Breakpoint 選擇理由（對應 F06 & T05）
- **Breakpoint 設定**：`@media screen and (max-width: 768px)`
- **選擇原因**：
  - 768px 是平板直向與手機尺寸的分界。在 768px 以上，雙欄 Grid 每一卡片至少有 340px 以上寬度，行寬適合眼睛閱讀；一旦低於 768px，若維持雙欄，卡片內文字會換行過於頻繁，影響可讀性。
- **桌面版（~1200px）與手機版（~390px）具體差異**：
  1. **導覽列**：桌面版為左右橫向對齊；手機版（390px）轉為垂直堆疊居中，避免導覽項目被截斷或水平溢出。
  2. **路線卡片區**：桌面版為 `2 欄` 對稱結構；手機版（390px）平順折疊為 `1 欄（1fr）` 垂直堆疊，單卡填滿寬度，閱讀體驗最佳。
  3. **數據方塊**：桌面版 4 欄水平展開；手機版轉換為垂直堆疊列表，每個數據塊 `width: 100%`，利於單手直向滑動檢閱。
  4. **操作按鈕**：桌面版為並排按鈕；手機版按鈕寬度展開為 100%，擴大手指觸控點擊熱區。

## 四、個人化設計決策與自主調整紀錄（對應 F07 與 AI 規範）
1. **個人化色彩與視覺決策**：
   - 採用**夜行冷光風格**：主背景使用極深的瀝青黑 `#0b0d12`，搭配大肚山藍色公路路燈的冷光藍 `#00d2ff` 作為主重點色，並以車尾燈警示橘 `#ff6b35` 作為分類標籤，貼合夜騎情境。
2. **針對 AI 建議的自主調整（自我修正項目）**：
   - **原 AI 建議**：在卡片網格使用 `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`。
   - **我的自主調整**：捨棄自動換行，改為在桌面版明確寫死 `repeat(2, 1fr)`，並在 768px media query 中明確改為 `1fr`。
   - **調整理由**：使用 `auto-fit` 時，在 820px～900px 區間容易出現上面排 3 張、第 4 張卡片落單在下一行左側的失衡情況；明確採用 2 欄轉 1 欄，能保證任何視窗寬度下卡片均為對稱偶數排列，版面更穩重。
